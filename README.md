# AI Skills Repository

This repository contains my collection of AI skill files and related project notes.

Each folder in this repo represents a focused skill or learning artifact, with content designed to capture reusable prompts, workflows, notes, and project-specific guidance for working with AI-assisted development.

## Purpose

This repo is a place to organize:

- AI skill definitions
- Project-specific knowledge files
- Reusable prompts and workflows
- Notes and examples for practical AI-assisted work

## Structure

- `onenote-meal-planner/` — project-specific skill and planning materials

## Notes

The goal is to keep useful AI workflows, prompts, and project context in one place so they can be revisited, refined, and reused over time.
